# Screenshot Branch

This branch contains automated screenshots for visual regression testing and documentation.

## Directories

- [Root Load](./root-load/) - Homepage screenshots captured immediately after page load
- [Root Wait](./root-wait/) - Homepage screenshots captured 8 seconds after initial load
- [About](./about/) - About page screenshots
- [Contact](./contact/) - Contact page screenshots
- [Research](./research/) - Research page screenshots
- [Work](./work/) - Work page screenshots
- [Viewer](./index.html) - Matrix view across all pages and resolutions

Each directory contains screenshots at various resolutions and a README with embedded images for easy viewing on GitHub.
